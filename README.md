# Patika Swift Projects

A collection of iOS development projects built while learning Swift and UIKit through Patika training and hands-on practice.

This repository contains practical exercises and sample applications covering fundamental iOS development concepts, UIKit components, navigation, networking, and data persistence.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [TodoListApp](./TodoListApp) | A task management application with create, read, update, and delete operations. Tasks are persisted using Core Data. | Swift, UIKit, Core Data |
| [FlickrApp](./FlickrApp) | A photo browsing application that fetches the latest photos and displays their details using the Pixabay API. | Swift, UIKit, URLSession, Codable, Pixabay API |

## Topics Covered

- **Swift Fundamentals** – Language syntax, types, functions, classes, structures, and protocols.
- **UIKit** – Building user interfaces with UIKit components.
- **Navigation** – Managing screen transitions and navigation flows.
- **Table Views** – Displaying collections of data using `UITableView`.
- **Networking** – Making API requests with `URLSession` and decoding JSON responses.
- **Data Persistence** – Storing and managing local data with Core Data.
